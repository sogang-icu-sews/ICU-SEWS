# ICU-SEWS GRU 학습 과정 및 최종 평가 보고서

- 작성일: 2026-11-12 (KST)
- 담당: 이택훈 — 머신러닝·딥러닝
- 최종 모델: **GRU v2 + Platt 확률 보정**
- 최종 실행 이름: `gru_v2_platt_final`
- 평가 범위: 개발 5-fold 실험, 보정·경보 정책 비교, 고정 test 평가, 환자 단위 bootstrap 95% 신뢰구간

## 1. 결과 요약

GRU의 학습률과 양성 가중치를 비교한 뒤, 비패혈증 환자 오경보율 약 10% 조건에서
조기 감지율과 Utility가 상대적으로 높았던 **v2 + Platt**를 최종 후보로 선택했다.
이후 개발 데이터 안에서 GRU 학습·보정·임계값 설정 환자를 분리하고,
모델과 임계값을 확정한 상태로 기존 test 15%를 평가했다.

최종 test는 **6,051명, 233,321개 시간 행**이다. 핵심 결과는 다음과 같다.

| 지표 | 최종 test 점수 | 환자 단위 bootstrap 95% 신뢰구간 |
|---|---:|---:|
| AUROC | **0.76316** | **0.74422–0.78153** |
| AUPRC (average precision) | **0.07032** | **0.05952–0.08511** |
| Brier ↓ | 0.01718 | 0.01573–0.01857 |
| Utility | **0.12141** | **0.09736–0.14558** |
| 비패혈증 환자 오경보율 | **9.303%** | **8.564–10.032%** |
| 추정 발병 전 0~12시간 감지율 | **27.632%** | **23.158–32.275%** |
| 감지 환자의 유효 경보 선행 시간 중앙값 | 8시간 | 7–9시간 |

Platt 보정은 평균 예측의 과대 추정을 줄였다. 전체 환자 오경보율의 관측값은 10% 미만이지만,
95% 신뢰구간 상한은 10%를 약간 넘는다. 따라서 오경보율 10% 이하를 보장했다고 표현하지 않는다.
주요 한계는 **낮은 조기 감지율**과 **병원별 경보 부담 차이**다.

별도 확인 없이 같은 값이라고 단정하지 않는다.

초기에는 로지스틱 회귀 기준선을 구축했으나, 이후 시계열 입력을 활용하는 GRU로 진행했다.
초기 로지스틱 기준선의 70/15/15 분할과 현재 GRU의 dev 85% / test 15% 분할은 다르므로,
이 보고서에서 해당 기준선 점수를 GRU와 직접 비교하지 않는다.

## 3. 데이터와 입력 구성

### 3.1 데이터와 환자 분할

- 데이터: PhysioNet Challenge 2019 학습 데이터 set A/B.
- 환자 수: 총 **40,336명** — A 20,336명, B 20,000명.
- 전체 시간 행 수: **1,552,210개**.
- 개발 데이터: **34,285명**, 환자 단위 5-fold, fold당 6,857명.
- test 데이터: **6,051명**. 개발 실험에서 평가하지 않고 최종 설정 확정 후 평가했다.
- 라벨: 공식 `SepsisLabel`을 사용하며 추가로 6시간 이동하지 않는다.
- 분할 기준: [`patient_split.csv`](../artifacts/patient_split.csv).

시간 행을 무작위로 나누지 않는다. 같은 환자의 모든 시간 기록은 같은 역할에 배정한다.
AUROC·AUPRC·Brier는 시간 행 단위이고, 환자 오경보율·조기 감지율은 환자 단위다.

### 3.2 EDA 결과를 반영한 전처리

데이터 담당의 전처리 설정 v4와 공통 모듈을 사용했다.
정제는 [`sews_features.py`](../data/src/sews_features.py), 스케일링·창 생성은
[`sews_preprocess.py`](../data/src/sews_preprocess.py), 세부 규칙은
[`preprocess_config.json`](../artifacts/preprocess_config.json)에 정의돼 있다.

| 입력 요소 | 구성 |
|---|---|
| 관측 창 | 현재 시간을 포함한 최근 최대 24시간 |
| 시간별 값 | 24개 변수 |
| 측정 mask | 지정된 21개 변수의 실제 측정 여부 |
| delta | 같은 21개 변수의 창 안 마지막 측정 이후 시간 / 24 |
| GRU 시간별 입력 차원 | 24 + 21 + 21 = **66** |
| 정적 입력 | Age, Gender, Unit_MICU, Unit_SICU, Unit_Unknown — **5개** |

창 안에서 과거 값으로만 forward fill하고, 학습 부분의 중앙값/IQR로 스케일링한다.
스케일링 후 ±10으로 제한하며, 아직 측정되지 않은 값은 0으로 대치한다.
기록 시작 전 padding은 GRU의 실제 관측 길이에서 제외한다.
현재 시점 이후 관측이나 다른 환자의 기록을 창에 포함하지 않는다.
관찰 시간 등 설정에서 제외한 특징을 별도로 추가하지 않았다.

5-fold 실험에서는 각 fold 학습 부분의 전처리 파라미터를 사용했다.
최종 학습에서는 GRU 학습 환자만으로 전처리 통계를 새로 산출했다.
이는 설정된 정제·누수 방지 절차를 사용했다는 의미이며, 원본 단위나 임상 타당성 전체를
별도로 검증했다는 의미는 아니다.

## 4. GRU 개발 실험 과정

### 4.1 실행 환경과 공통 설정

로컬에 학습용 CUDA GPU를 사용할 수 없어 Google Colab GPU로 진행했다.
노트북은 별도 Python 3.10 환경과 PyTorch 2.8.0 CUDA 설치를 사용하도록 구성했다.
실제 GPU 종류·총 학습 시간은 공유된 결과만으로 확정할 수 없어 성능 비교 항목에 넣지 않았다.

| 항목 | 개발 실험의 공통 설정 |
|---|---|
| GRU | hidden 64, 1 layer, 분류기 앞 출력 dropout 0.2 (1층 GRU 내부 dropout은 없음) |
| 정적 변수 결합 | GRU의 마지막 hidden state와 정적 입력 5개 결합 |
| 출력 | 이진 분류 logit, sigmoid로 확률 산출 |
| 손실 | BCEWithLogitsLoss |
| 최적화 | Adam, gradient norm clipping 1.0 |
| 배치 크기 | 128 |
| 최대 epoch / patience | 30 / 5 |
| 체크포인트 선택 | 검증 AUPRC가 가장 높은 epoch |
| seed | 기본 42, fold k의 학습 seed는 42+k |
| 재개 | 매 epoch 가중치·optimizer·난수 상태를 Drive에 저장 |

### 4.2 v1: 초기 설정과 학습 이력

v1은 학습률 **0.001**, 양성 가중치 사용으로 시작했다.
양성 가중치는 해당 학습 부분의 음성 시간 행 수 / 양성 시간 행 수로 계산했다.
fold 0에서 관찰된 이력은 다음과 같다.

| Epoch | 학습 loss | 검증 AUPRC |
|---:|---:|---:|
| 1 | 1.141491 | **0.075112** |
| 2 | 1.042337 | 0.073761 |
| 3 | 0.954234 | 0.063538 |
| 4 | 0.886660 | 0.058473 |
| 5 | 0.825712 | 0.048146 |
| 6 | 0.760070 | 0.047071 |

학습 손실은 감소했지만 검증 AUPRC는 첫 epoch 이후 하락했다. 일반화 성능 악화와
일치하는 패턴이며, 과적합 가능성을 고려해 학습률을 낮추는 실험으로 진행했다.
학습 손실과 검증 AUPRC는 서로 다른 지표이므로 두 곡선만으로 원인을 확정하지는 않는다.
최종 예측에는 마지막 epoch가 아닌 검증 점수가 가장 높았던 체크포인트를 사용했다.

### 4.3 v2·v3: 학습률과 양성 가중치 비교

| 실험 | 학습률 | 양성 가중치 | 최적 epoch (fold 0→4) |
|---|---:|---|---|
| v1 | 0.001 | 사용 | 1, 1, 1, 1, 2 |
| v2 | **0.0003** | 사용 | 2, 2, 3, 3, 3 |
| v3 | 0.0003 | **미사용** | 4, 2, 2, 3, 3 |

아래는 **보정 전, 개발 5-fold 평균 ± 표준편차**다. 신뢰구간이나 최종 test 점수가 아니다.

| 실험 | AUROC | AUPRC | AUROC (≤60h) | AUPRC (≤60h) | Brier ↓ |
|---|---:|---:|---:|---:|---:|
| v1 | 0.7800 ± 0.0101 | 0.0759 ± 0.0022 | 0.7689 ± 0.0139 | 0.0485 ± 0.0054 | 0.1293 ± 0.0368 |
| v2 | 0.7822 ± 0.0170 | **0.0795 ± 0.0025** | 0.7729 ± 0.0146 | **0.0518 ± 0.0057** | 0.1307 ± 0.0236 |
| v3 | **0.7876 ± 0.0102** | 0.0779 ± 0.0041 | 0.7728 ± 0.0083 | 0.0499 ± 0.0059 | **0.0172 ± 0.0001** |

v2는 v1보다 모든 fold의 AUPRC가 높아졌다. 평균 AUPRC의 상대 증가는 표시값 기준 약 4.7%다.
v3는 AUROC와 보정 전 Brier가 더 좋았지만 AUPRC는 v2보다 낮았다.
양성 가중치 사용 여부에 따라 확률 크기도 크게 달라져, 보정 전 Brier만으로 모델을 선택하지 않고
확률 보정과 같은 경보 부담에서의 성능을 추가 비교했다.

## 5. 확률 보정과 경보 정책 비교

### 5.1 개발 비교의 설계

각 원래 검증 fold 안에서 환자를 병원×패혈증 여부로 층화해 3그룹으로 나눴다.
세 그룹이 Platt/isotonic 학습, 경보 임계값 설정, 평가 역할을 번갈아 맡도록 했다.
평가에 사용되는 환자는 해당 GRU의 가중치 학습에서 제외돼 있다.
두 모델은 동일한 환자 역할 배정을 사용했고, 각 개발 시간 행은 평가에 한 번 참여했다.

다만 epoch와 모델 설정 선택에 이미 개발 라벨을 사용했으므로, 이 결과는 **개발 분석**이다.
독립 test 성능이나 완전한 nested CV로 해석하지 않는다.
전체 예측을 합친 pooled 점수와 5개 fold 점수의 단순 평균도 구분한다.

### 5.2 전체 개발 예측을 합친 확률 성능

| 모델 | 보정 | AUROC | AUPRC | Brier ↓ | Brier skill |
|---|---|---:|---:|---:|---:|
| v2 | raw | 0.77761 | 0.07748 | 0.13062 | -6.39487 |
| v2 | **Platt** | 0.78131 | 0.07598 | **0.01713** | **0.03042** |
| v2 | isotonic | 0.78068 | 0.07417 | 0.01716 | 0.02857 |
| v3 | raw | 0.78407 | 0.07690 | 0.01716 | 0.02852 |
| v3 | Platt | **0.78664** | **0.07635** | **0.01713** | 0.03029 |
| v3 | isotonic | 0.78522 | 0.07404 | 0.01716 | 0.02872 |

Platt는 `sigmoid(a × logit(clip(p_raw)) + b)` 형태의 비가중 로지스틱 회귀다.
두 모델 모두 Platt 후 Brier가 약 0.01713으로 비슷해졌다.
v2는 보정 전 평균 예측 26.341%가 보정 후 1.797%로 낮아져, 개발 양성 시간 비율 1.799%에 가까워졌다.
isotonic은 이 비교에서 Platt보다 AUPRC가 낮았다.

개발 pooled 예측에는 여러 보정기가 섞여 있으므로 보정 전후 AUROC·AUPRC가 달라질 수 있다.
각 단일 Platt 함수의 순위 보존과 pooled 순위 변화는 구분해야 한다.

### 5.3 경보 기준별 v2 + Platt / v3 + Platt 비교

| 기준 | 모델 | 실제 환자 오경보율 | 0~12h 감지율 | Utility |
|---|---|---:|---:|---:|
| 시간 행 특이도 95% 목표 | v2 + Platt | 15.906% | 44.497% | 0.20585 |
| 시간 행 특이도 95% 목표 | v3 + Platt | 17.114% | 47.554% | 0.20442 |
| **환자 오경보율 10% 목표** | **v2 + Platt** | **9.968%** | **34.431%** | **0.15170** |
| 환자 오경보율 10% 목표 | v3 + Platt | 10.053% | 32.502% | 0.14171 |
| Utility 최대화 | v2 + Platt | 45.337% | 75.494% | 0.29944 |
| Utility 최대화 | v3 + Platt | 44.202% | 76.952% | 0.30139 |

**선택 근거:** 환자 오경보율을 약 10%로 제한하는 조건에서 v2가 v3보다 0~12h 감지율과 Utility가 높았다.
Utility 최대화 조건은 감지율이 높지만 비패혈증 환자의 약 44~45%에 경보가 발생했다.
따라서 이번 연구의 주 경보 기준은 환자 오경보율 10% 목표로 정하고 v2 + Platt를 선택했다.
이는 모든 기준에서 v2가 우월하다는 뜻은 아니며, v2-v3 차이의 통계적 유의성을 검정한 결과도 아니다.

Platt는 같은 순위를 유지하므로 이번 비교에서 raw와 Platt의 순위 기반 경보 결과는 같았다.
보정은 확률 해석을 개선하는 역할이며, 감지 성능 자체의 향상을 보장하지 않는다.

## 6. 최종 모델 학습과 임계값 확정

### 6.1 최종 실행 코드의 고정 설정

| 항목 | 설정 |
|---|---|
| 모델·입력 | v2와 동일한 GRU 구조 및 입력 방식 |
| 학습률·배치 | 0.0003 / 128 |
| 양성 가중치 | 최종 GRU 학습 부분의 음성/양성 시간 행 비율 |
| 학습 횟수 | **3 epochs 고정** |
| 횟수 결정 근거 | v2 개발 best epoch [2,2,3,3,3]의 중앙값 |
| 모델 초기화 | 기존 fold 가중치 재사용 없이 새로 학습, seed 42 |
| 보정 | 별도 환자 그룹의 예측으로 Platt 학습 |
| 임계값 | 별도 환자 그룹에서 환자 오경보율 10% 목표 |

최종 학습에서는 보정·임계값 설정 그룹으로 early stopping을 다시 수행하지 않았다.
3 epochs가 새 표본에서 항상 최적이라는 보장은 없지만, test를 보기 전에 고정한 규칙을 유지했다.

### 6.2 최종 환자 역할

| 역할 | 환자 수 | 전체 대비 비율(약) | 사용 범위 |
|---|---:|---:|---|
| GRU 학습 | 27,428 | 68% | 기존 dev fold 0~3, 전처리 통계·가중치 학습 |
| Platt 학습 | 3,428 | 8.5% | dev fold 4를 층화 반분한 한 그룹 |
| 임계값 설정 | 3,429 | 8.5% | dev fold 4의 나머지 그룹 |
| 최종 test | 6,051 | 15% | 기존 test 환자, 최종 평가만 수행 |

환자 분할 seed는 42이며 fold 4를 병원×패혈증 여부로 층화했다.
개발 85% 전부를 최종 GRU의 가중치 학습에 사용한 것이 아니다.
전처리 중앙값/IQR도 GRU 학습 환자만으로 산출했고, 동일한 값을 나머지 역할에 적용했다.
보정·임계값 환자는 앞선 개발 선택에 쓰였으므로 그 그룹의 점수를 새로운 독립 검증으로 제시하지 않는다.

### 6.3 확정된 경보 규칙

```text
p_calibrated >= 0.08541464768866672 이면 해당 시간에 경보
```

임계값은 비패혈증 환자별 기록 전체의 최대 보정 확률을 기준으로 설정했다.
동점을 보수적으로 처리해 설정 그룹의 환자 오경보율이 10% 이하가 되도록 했다.
같은 임계값을 test 전체와 병원 A/B에 적용했다.
**10% 목표는 확률 임계값 0.10을 뜻하지 않는다.**

모델·전처리·Platt·임계값을 `frozen.json`의 해시로 고정한 후 test를 평가했다.
경보 억제 시간(cooldown), 연속 경보 통합, 첫 경보 이후 중단은 적용하지 않았다.

## 8. 환자 단위 bootstrap 95% 신뢰구간

### 8.1 계산 방법

1. test 환자 N=6,051명 중 N명을 복원추출한다.
2. 선택한 환자의 모든 시간 기록을 함께 반영한다. 같은 환자가 k번 뽑히면 k번의 기여를 반영한다.
3. 모델·Platt·임계값을 고정한 채 지표를 다시 계산한다.
4. **2,000회, seed 42**로 반복하고 각 지표 분포의 **2.5·97.5 percentile**을 사용한다.

병원·패혈증 여부를 고정하지 않는 일반 환자 cluster bootstrap이다.
환자 수를 기준으로 추출하지만 시간별 지표는 원래 평가와 같은 시간 행 가중 방식으로 계산한다.
Utility는 환자별 Utility의 단순 평균이 아니라, 표본 전체의 분자·분모 합으로 계산한다.
환자를 복제한 뒤 같은 ID로 합쳐버리는 오류를 피하도록 환자 추출 횟수를 가중치로 반영했다.

전체·병원 A/B·≤60h 하위집단에 같은 전체 환자 재추출을 적용했다.
환자 전체 기록이 필요한 경보 지표는 ≤60h로 잘라 계산하지 않았다.
공유된 모든 지표에서 **2,000/2,000회가 유효**했다.

### 8.2 전체 확률 성능의 신뢰구간

| 지표 | 점수 | 95% 신뢰구간 |
|---|---:|---:|
| AUROC | 0.76316 | 0.74422–0.78153 |
| AUPRC | 0.07032 | 0.05952–0.08511 |
| Brier ↓ | 0.01718 | 0.01573–0.01857 |
| Brier skill | 0.02634 | 0.01959–0.03295 |

AUROC 구간은 무작위 순위 기준 0.5보다 높고, Brier skill과 Utility의 구간도 0보다 높다.
현재 고정 모델과 표본 추출 가정에서 기준보다 나은 성능을 뒷받침하지만,
임상 적용 가능성이나 새로운 병원에서의 성능을 입증하는 결과는 아니다.
AUROC 0.76316을 정확도 76.316%로 표현하지 않는다.

### 8.3 신뢰구간의 해석 범위

- 고정된 학습 모델·Platt·임계값에 조건부인 **test 환자 표본 변동성**을 나타낸다.
- 학습 데이터·학습 seed·모델 선택·Platt 학습·임계값 선택을 반복한 변동성은 포함하지 않는다.
- 환자를 독립 추출 단위로 가정한다. 새 병원으로의 일반화 변동은 추정하지 않는다.
- 각 지표의 개별 95% 구간이며 다중 비교를 보정한 동시 신뢰구간은 아니다.
- “참값이 이 구간 안에 있을 확률이 정확히 95%”라는 뜻으로 해석하지 않는다.

## 9. 지표 정의와 한계

| 지표 | 이 보고서의 정의 |
|---|---|
| AUROC / AUPRC | 시간 행 라벨과 예측 확률로 산출. AUPRC는 average precision 구현 |
| Brier | 시간 행별 (예측 확률−라벨)²의 평균 |
| Brier skill | 1−Brier/상수 확률 기준 Brier |
| 환자 오경보율 | 기록 전체가 음성인 환자 중 한 번 이상 경보를 받은 비율 |
| 추정 발병 시각 | 첫 양성 라벨의 ICULOS +6시간 |
| 6~12h 감지율 | 추정 발병 기준 [-12,-6]시간 구간에서 한 번 이상 경보를 받은 평가 가능 패혈증 환자 비율 |
| 0~12h 감지율 | 추정 발병 기준 [-12,0)시간 구간에서 한 번 이상 경보를 받은 평가 가능 패혈증 환자 비율 |
| 선행 시간 | 위 [-12,0) 구간에서 감지된 환자의 최초 유효 경보 선행 시간 |
| Utility | 저장소의 PhysioNet 정규화 Utility 정의. 0은 전혀 경보하지 않는 기준 |

발병 시각은 실제 임상 발생 시각을 직접 관측한 값이 아니라 라벨에서 역산한 값이다.
첫 행부터 양성인 환자는 조기 감지·선행 시간에서 제외하지만 Utility에는 포함한다.
경보는 매시간 판단하며 별도 cooldown이 없다.

주요 한계는 다음과 같다.

1. 오경보율 약 10% 조건에서 0~12h 감지율은 27.632%로, 다수의 평가 대상 환자를 감지하지 못했다.
2. 전체 오경보율의 신뢰구간 상한이 10%를 약간 초과하고, 병원 A에서는 구간 전체가 10%를 초과했다.
3. ≤60h 하위집단에 과대 예측이 남고, 상수 확률 기준 대비 Brier 개선은 제한적이다.
4. 개발 설정을 선택한 결과와 test 결과의 차이가 존재하며, 단일 최종 모델의 결과다.
5. 동일 원자료의 보류 환자 평가로, 독립적인 외부 병원·시기 검증과 임상 적용 검증은 수행하지 않았다.
