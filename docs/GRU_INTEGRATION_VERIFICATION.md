- 기능 구현 커밋: 0dff6c1
- 모델 버전: gru-v2-platt-final-9c740ece0137

## 검증 방법

팀이 제공한 prepared 데이터에서 환자별 최근 최대 24시간 기록을
구성하여 FastAPI TestClient로 /predict에 전달했다.

응답의 보정 확률과 경보 여부를
calibration_predictions.parquet의 기준 결과와 비교했다.

검증 전 모델 파일 및 준비 데이터의 해시와 데이터 정렬을 확인했다.
모델 재학습이나 확률 보정값·경보 기준 변경은 수행하지 않았다.

## 검증 범위와 결과

- 비교 사례: 80개
- 입력 길이: 1~24시간 모두 포함
- 경보 기준 근처 및 기준 이상·미만 사례 포함
- 확률 절대 오차 허용치: 1e-6
- 관측된 최대 확률 차이: 약 9.723e-8
- 경보 판단 불일치: 0개
- 결과: 80개 모두 통과

## 실행 방법

프로젝트 루트에서 다음 명령을 실행한다.

    uv run --no-sync python check_gru_reference.py

스크립트의 ROOT는 팀 자료를 압축 해제한 경로,
MODEL_DIR는 서버에서 사용하는 GRU 모델 폴더를 가리킨다.
다른 컴퓨터에서는 해당 경로를 조정해야 한다.

상세 결과는 gru_reference_results.csv에 저장된다.

## 제한 사항

이번 검증은 정제된 데이터에서 구성한 80개 입력 사례에 대한
백엔드 결과 재현성 검사다.

전체 데이터에 대한 모델 성능 평가나 원본 PSV 정제 과정 전체의
독립 검증을 의미하지 않는다.

프론트엔드 파일 업로드부터 결과 표시까지의 연동과
실제 배포 환경 검증은 별도로 진행해야 한다.
